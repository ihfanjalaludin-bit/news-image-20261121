A Python 3 program (standard library only) that sums up Saturday 21 November 2026's world news in one image. It draws a front-page digest — a dated masthead, four story panels (missiles land in Poland; Cyclone Akvan hits Odisha; the World Court's Myanmar genocide ruling; stocks slide into correction) and an "Also Today" strip — and writes it deterministically to `$MAKEFUN_OUTPUT_DIR/entry.png` (fallback `/output/entry.png`), a 1024×1024 PNG. It rasterises real TrueType glyph outlines itself, so every line, lowercase included, renders fully legibly. No network at runtime; two runs produce byte-identical output.

## Run it

```sh
python3 main.py
```
